Local chat, including when you’re offline.

Quenderin runs the model on your device and stores your conversations there. It can help with drafts, explanations, and code. Response quality and speed depend on the model and your hardware; answers can be incorrect. See the measurements and limitations.

Advanced · source CLI

The App Store apps include local tools. The broader computer-control workflow below runs from the source CLI on macOS.

Computer tools through the macOS CLI

The source CLI can use a local model to organize files, interact with Mac apps, and run Apple Shortcuts. These tools have permissions and controls for reviewing actions:

  • Action approval. The CLI asks before changes by default. App control requires approval even when auto-approve is enabled.
  • Task history. Review the local log with quenderin history. Use quenderin undo to reverse supported file operations.
  • Preview. Use --dry-run to inspect proposed actions before running them.
  • Local processing. The model runs on your Mac. Apps and Shortcuts it interacts with may use their own network connections.

Features

What the app includes

Once your model is installed, chat works without an internet connection. Model discovery and downloads need a connection.

Works in airplane mode

The installed model runs on your device through llama.cpp. Downloads, model search, and release-list updates use the internet; they do not send your chats or attached files.

$0

The app has no subscription or per-message charge.

Replies are generated on your hardware, without a paid inference service. The app’s source code is available under the MIT license.

The apps include local tools. Broader Mac app control is available through the source CLI. Safety checks restrict sensitive actions involving:

PayDeletePasswordTransfer

Tool availability and approval controls differ between the apps and the source CLI. The CLI provides a task log, action previews, and undo for supported file operations. Review actions before allowing them.

Chat history stays on your device. No account is required.

Quenderin does not send conversations to an inference service or collect analytics and telemetry. Model downloads, optional search, and release information use network requests.

Memory estimates help you choose a model for your device.

PiM-series

The model library shows whether a model fits, is tight on memory, or is too large. These are estimates; available memory and model settings affect performance.

The source code is available under the MIT license.

The repository contains the app code, model integration, and tool safety checks, along with build instructions. github.com/alikatgh/quenderin

Interrupted model downloads can be resumed.

Quenderin supports resuming interrupted downloads and checks model files before loading them. Background download behavior depends on the platform.

Before going offline

Download and check your model first.

Install a model while you have an internet connection, then try a conversation in airplane mode. This lets you check that the model loads and runs on your device before you need it offline.

FAQ

Common questions

Details about cost, privacy, supported devices, and installation.

Still have a question?

Ask on GitHub
Does it cost anything?

Quenderin is free to use, with no subscription or per-message charge. Models run on your own hardware. The app’s source code is MIT licensed.

Is my data sent anywhere?

Your chats and files stay on your device. Model downloads, optional catalog search, and release metadata use network requests; inference works offline. There are no analytics, accounts, or telemetry.

What devices does it run on?

Quenderin is free on the App Store for Mac and iPhone. Windows and Linux previews are available from GitHub. The native Android app is in closed beta on Google Play.

Do I need a powerful phone?

Model requirements vary. Quenderin estimates which models fit your device’s memory. Smaller models use less memory, but their answers may be less capable.

Where can I install it?

The Mac and iPhone apps are on the App Store. The download page also links to Windows and Linux previews and the Android closed beta.
