Download Quenderin

Command line & local agent

Use the same local models directly from your terminal, or drive governed file tasks on Mac, Windows, and Linux with approval and undo.

git clone https://github.com/alikatgh/quenderin.git
cd quenderin && npm install && npm run build:tsc && npm link
git diff | quenderin chat -p "review this change"
quenderin do --dry-run "organize my downloads"
quenderin history

Build and link from the open-source repository today; an npm package is planned. CLI & agent docs · CLI announcement · Why a local agent

Before you download

Small local models

Open on-device models can be confidently wrong, outdated, or unsuitable, and Quenderin applies no server filter.

No professional advice

Never treat local model output as medical, legal, financial, or safety advice. Verify important facts independently.

As-is license

By downloading Quenderin you agree to the Terms of Use (no warranty, zero liability); the app confirms this on first launch.

What you're downloading

Streaming local chat

Desktop v0.2.x and mobile native apps run GGUF chat offline on your hardware with persistent local history.

Verified model library

Curated Llama, Qwen, DeepSeek-R1, Mistral, Gemma 3 & 4, and Phi models (0.4–9 GB) with SHA-256 verification and RAM checks.

Governed local tools

File and task workflows ask permission before acting. See how it works and full catalog docs.
