Website & docs update

A self-hosted documentation portal and open-source typography

22 November 2026 · Quenderin

Quenderin’s website now includes a full technical documentation portal at quenderin.org/docs/ alongside updated open-source typography and iconography across the homepage, overview, model pages, and blog. Everything remains static, MIT/OFL/ISC-licensed, and 100% self-hosted with zero third-party network calls.

30 documentation guides, generated from source

Until now, deep architecture notes, the HTTP/WebSocket API contract, hardware fit rules, inference 101 walkthroughs, native iOS/Android guides, and the failure-mode ledger lived mainly as Markdown files inside the GitHub repository.

  • 116 canonical Markdown sources in one portal. Organized into seven tracks: Quickstart & Setup, Governed Local Agent, Model Catalog, the 101 Inference Series, Architecture & API, Platforms & Releases, and Known Failure Modes.
  • Backed by shared JSON manifests. The model, image, experimental runtime (Prism, Muse Spark, Diffusion), remote harness, and performance tables in the docs pull directly from shared/*.json so store status stays separate from source-only integrations.
  • Zero-network search & light/dark parity. Press / or Cmd/Ctrl+K on any docs page to search titles, headings, source file paths, and excerpts from the local search index without calling an external service.
  • Machine-checked links. python3 scripts/generate_website_docs.py --check verifies deterministic output and confirms zero broken internal links across all 30 HTML files.

Three self-hosted fonts: DINish, ChunkFive, Lucide

Every marketing, blog, legal, and documentation route now loads three local WOFF2 font families from website/fonts/ under the site’s existing font-src 'self' Content Security Policy:

  • DINish variable sans (SIL OFL 1.1). Powers UI labels, body copy, tabular numbers in model/benchmark tables, condensed uppercase kickers (wdth: 82), oblique emphasis, and bold headings for non-Latin scripts such as Russian and Arabic.
  • ChunkFive (SIL OFL 1.1). Gives Latin display headlines on the homepage, detail hero, callout bands, legal pages, and docs titles unmistakable slab character while keeping a crisp single-weight 400 cut.
  • Lucide icon font (ISC). Scoped under .qi / .qi-* classes across navigation links, the homepage Docs action, feature accordions, roadmap status pills, docs callouts, copy-code buttons, and sidebar categories—keeping existing custom SVG icons untouched.

What this update does not change

This is a website and documentation update. It does not ship a new App Store or Google Play app binary or alter model test status: Mac and iPhone on the App Store remain 0.6.0 (with 0.6.1 prepared in source and unsubmitted), Android remains in closed testing (0.2.0), and experimental engines such as Bonsai 2 / Prism and Muse Spark remain labeled by their actual verification boundary.

Verified locally across light and dark themes at desktop (1440 px) and mobile (390 px) viewports including English, Russian, and RTL Arabic layouts, alongside catalog parity checks and website test suites. Ready to explore: open the Documentation Portal → · Read the changelog · View updated roadmap.
