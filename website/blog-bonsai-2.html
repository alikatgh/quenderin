Experimental model release

Bonsai 2 27B in Quenderin

12 October 2026 · Quenderin

Quenderin 0.2.1 adds Ternary Bonsai 2 27B from PrismML as an experimental manual model option on Windows and Linux. The desktop installers include the pinned Prism llama.cpp CPU runtime required to run its packed ternary weights. The model downloads separately.

The native iPhone and Mac updates, version 0.3.0, have also been submitted to Apple with the Prism runtime included. Both are waiting for App Review and will release automatically after approval. Bonsai will become available in those updates; the current 0.2.0 App Store apps do not include it.

The Android integration is included in the source pull request, with build instructions. Its store release remains separate.

16 October update: Read about the smaller Bonsai 2 models and Muse Spark Open compatibility.

The model

Bonsai 2 27B is based on Qwen3.8 27B and is published under Apache 2.0. Its ternary weights use three values, −1, 0, and +1, with shared scaling factors. The PTQ1_0 language-model file is 5.946 GB, roughly 6 GB to download. PrismML reports a footprint about nine times smaller than the FP16 baseline. See the official model card and PrismML’s announcement for the format and evaluation details.

A compatible runtime is required

This GGUF uses PrismML’s custom packed weights and a matching Hadamard transform during inference. It requires their llama.cpp runtime. Quenderin checks runtime compatibility before installation and loading, so a build without that support cannot treat Bonsai as an ordinary downloadable model.

In a compatible build, open the model library, choose Bonsai 2 27B, and confirm the download. Adding the model does not change your selected model or start an automatic download. Existing default recommendations remain the same.

Download size and memory are different

The roughly 6 GB file describes the language weights. Running them also needs context, caches, and working buffers. A phone’s total RAM is different from the memory available to an app, so a 6 GB download does not mean a 6 GB phone can run it. Quenderin still applies its device memory checks; a longer conversation can need more memory.

What we checked

The Windows and Linux release checks execute the native runtime from the packaged app. The Linux check also verifies the exact model file’s SHA-256, loads it through the packaged runtime, and generates a text response using a 512-token context. Physical-phone testing was skipped for this release.

The signed iOS and Mac updates passed runtime, catalog, and code-signature checks in Xcode Cloud. The Mac check also executed the runtime’s packed-ternary capability probe.

Device-specific speed, sustained performance, and answer quality remain experimental. We will record measured Quenderin results separately from the model publisher’s benchmarks.
