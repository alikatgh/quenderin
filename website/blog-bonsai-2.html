Experimental Bonsai 2 27B integration

12 October 2026 · Quenderin

Quenderin’s source model library now includes Ternary Bonsai 2 27B from PrismML. It is a manual option for compatible builds of the native Apple and Android apps and the desktop runtime. The integration pull request includes the source changes and build instructions. Distribution through store builds is a separate release.

The model

Bonsai 2 27B is based on Qwen3.8 27B and is published under Apache 2.0. Its ternary weights use three values, −1, 0, and +1, with shared scaling factors. The PTQ1_0 language-model file is 5.946 GB, roughly 6 GB to download. PrismML reports a footprint about nine times smaller than the FP16 baseline. See the official model card and PrismML’s announcement for the format and evaluation details.

A compatible runtime is required

This GGUF uses PrismML’s custom packed weights and a matching Hadamard transform during inference. It requires their llama.cpp runtime. Quenderin checks runtime compatibility before installation and loading, so a build without that support cannot treat Bonsai as an ordinary downloadable model.

In a compatible build, open the model library, choose Bonsai 2 27B, and confirm the download. Adding the model does not change your selected model or start an automatic download. Existing default recommendations remain the same.

Download size and memory are different

The roughly 6 GB file describes the language weights. Running them also needs context, caches, and working buffers. A phone’s total RAM is different from the memory available to an app, so a 6 GB download does not mean a 6 GB phone can run it. Quenderin still applies its device memory checks; a longer conversation can need more memory.

The smaller file makes this model worth integrating, but it does not establish its speed, sustained performance, or answer quality inside Quenderin. Device-specific performance remains experimental. We will record measured Quenderin results separately from the model publisher’s benchmarks.
