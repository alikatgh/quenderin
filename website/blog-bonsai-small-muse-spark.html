Model library update · in development

Bonsai 2 for smaller devices, and Muse Spark Open

16 October 2026 · Quenderin

We have added PrismML’s Bonsai 2 2B, 4B, and 9B to the source catalogs used by Quenderin for Android, iPhone, and Mac. They join the existing 27B option as experimental models you can select manually in a build with the compatible Prism runtime. This is preparation for an app update; it does not mean new binaries have reached the stores.

Three smaller downloads

The new models are based on Qwen3.5 and published under Apache 2.0. Quenderin uses their PTQ1_0 language weights:

  • Bonsai 2 2B: 0.43 GB.
  • Bonsai 2 4B: 0.95 GB.
  • Bonsai 2 9B: 2.00 GB.

Each download is pinned to an exact publisher revision and SHA-256 checksum. These sizes cover the language-model file, not a vision projector. Image understanding is not enabled by this update. See PrismML’s announcement for its evaluations and supported runtimes.

Choosing a model that fits

The smaller models now have separate memory estimates instead of inheriting the 27B model’s requirement. The app still reserves working-memory headroom and checks the memory available to it. Download size alone does not establish whether a model will run well on your phone or computer.

Bonsai requires Prism’s custom runtime. Builds without that runtime show the requirement and disable selection in the latest-releases list. Compatible builds retain the 4,096-token context cap. Existing default recommendations and your selected model stay the same; viewing or refreshing the library never starts a model download.

Where Muse Spark Open fits

Meta’s Muse Spark Open is a separate class of model: 816B total parameters, 42B active per token, and a context window of 1,048,576 tokens. The active parameter count describes how much computation is used per token; it does not reduce the stored model to 42B parameters.

The native release candidate adds experimental Muse text-chat support through a verified runtime backport, a 22-part pinned installer, and a Muse-specific chat adapter. The Q2_K download is about 304 GB; normal phones do not meet the memory requirement. A compatible build and the full hardware checks are required before selection. This work does not add distributed execution, a remote inference connection, vision/audio input, or Muse tool calling. Read the engineering post for the implementation, current verification limits, and planned improvements.

What this update verifies

This update checks publisher metadata, catalog consistency, memory rules, runtime gates, and release-feed behavior. No model weights were downloaded locally for this work, and no simulator or physical device was used. Inference quality, device performance, signed builds, and store distribution remain separate verification and release steps.
