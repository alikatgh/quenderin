Development update

Chat improvements, native app work, and ongoing maintenance

28 October 2026 · Quenderin

Quenderin’s next update is taking shape across chat, model setup and the native apps. Here is what has changed recently, what we are still testing, and what you can download today.

More predictable local conversations

Automatic model selection, merged on 24 October, chooses among installed models using the conversation and available memory. It does not start model downloads. Stop and cancellation fixes and Continue state improvements followed on 26 October, alongside remote conversation draft recovery.

On 27 October, accessibility and error recovery work improved composer labels, contrast, model filters and retry actions. Native cancellation and Unicode parsing fixes also merged. These are source changes for upcoming builds; MAX remains an unavailable experimental backend.

Native 0.6 work is in progress

The Android update is reshaping navigation and setup, with adaptive layouts, light and dark themes, and a way to review an excerpt before sending an AI issue report. The reporting receiver and its privacy information are deployed; the Android reporting feature is still unreleased. The Apple 0.6 foundation is being prepared in parallel.

Both changes are still open for review and testing. Cloud verification includes signed Apple archives and Android compilation, core and unit checks. UI tests still have failures, including Android Back navigation, so native release verification remains unfinished.

The optional DeepSeek and My Computer connection work merged on 23 October. External connections remain separate choices with explicit consent before sending a conversation. The source integration does not establish live provider inference or new App Store availability.

Maintenance you can inspect

On 28 October, we configured CodeQL scanning, dependency review, grouped security updates and private vulnerability reporting. Android dependency reporting also passed its first trusted run. These checks support continued maintenance and do not establish that every dependency or security risk is resolved.

The model discovery cards now place local family or author marks beside recognized models, with model names and the GGUF publisher still in text. Discovery remains a list of files to explore, not a claim that each model has passed inference tests or fits your device.

What is available today

As checked on 28 October, Mac and iPhone 0.5.0 (22) are available on the App Store. Android 0.2.0 remains in the Google Play closed test. Apple 0.6 has not been submitted, and the Android 0.6 draft has not been uploaded.

Download the current apps, join Android testing, or follow the commit history and build checks. New model inference and the native release journeys still need their own validation.
