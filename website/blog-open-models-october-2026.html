Engineering update · experimental source integration

This week’s open models in Quenderin

18 October 2026 · Quenderin

Quenderin’s October 18 engineering candidate connects this week’s models to the app: 28 text-model choices, still-image questions, memory proposals, image generation and dedicated Granite and Step 5 tools. The source includes native Apple, Android and desktop workflows. Integrated hosted builds and package checks have passed. These additions have not had full-weight inference validation. This is not a new store release.

Text models, from small downloads to large workstations

The text catalog adds MiniCPM-V 4.7 1B and 35B-A3B, LFM2.5 24B-A2B, five Jais 3 sizes, Nemotron 3.5 Bolt 74B-A9B and Beam 1.0. Bonsai 2 2B, 4B, 9B and 27B remain in the library. These experimental choices are manual selections, with pinned files, compatible-runtime checks and memory gates.

Jais, Bolt, Beam and Muse need architecture or conversation handling beyond a catalog entry. Their adapters follow the publisher’s prompt format and keep private reasoning out of the displayed answer. Beam and Muse text chat now have native and desktop adapters and complete multipart installation; tools and multimodal inputs are unavailable on those paths.

Large models still need all their weights. Beam’s four parts total 133,885,310,500 bytes, with a 160 GiB whole-model memory floor; context and working buffers may require more. Its small first part contains metadata, not the complete model. Muse requires all 22 parts, totaling 304,080,474,208 bytes. An active parameter count is not a storage or RAM estimate.

Ask about one image

The dedicated Vision workflow installs and verifies a complete language-model/projector pair for MiniCPM-V 4.7 1B, MiniCPM-V 4.7 35B-A3B or Nemotron 3.5 Super VL 120B-A12B. Their available-memory floors are 8, 32 and 96 GiB, respectively. The same pair manifests serve the native and desktop workflows.

Choose one JPEG or PNG and ask a question. Input is limited to 8 MiB, 4,096 pixels per side and 16 million pixels, with a bounded final answer. The app preserves the selection and question after an error. This is a still-image tool; video, audio and tool execution are unavailable.

Memory proposals and Granite chat

Hy-Memory has a separate proposal workflow in the native and desktop source. You choose the conversation to submit, review the proposed facts and explicitly select each item to save. Proposals start unchecked. Strict JSON validation and a private approved-memory store keep generated text from becoming a saved fact automatically. The pinned community conversion is an 18.24 GB download and needs at least 32 GiB of available memory; its conversion metadata has been checked, but its full weights have not been inference-tested.

Granite Switch 4.1 8B also has a dedicated native and desktop chat path. An offline converter checks the official checkpoint already on your disk and creates a new GGUF plus a conversion receipt. Import both files together; the app checks their hashes, architecture and resource requirements before loading. It requires at least 32 GiB of available memory, with further allowance for the file and context. The receipt records the local conversion; it is not a publisher signature or an inference result. Speech, decision and guardian modes are not enabled.

Step 5 on your own CUDA host

Step 5 Preview runs through its pinned official CUDA backend on an existing, suitably sized Linux GPU host. Quenderin’s launcher verifies the complete installed checkpoint and backend source, then starts a bounded gateway. It does not download weights or provision a server.

Native and desktop clients ask for consent before sending text to the selected host. Use an existing SSH tunnel or an independently secured HTTPS proxy; do not expose the loopback gateway publicly. This is remote specialist chat, not on-phone Step 5 inference. The current clients accept text only.

A separate local image engine

The Images workflow covers FLUX 3 Image Klein and MOSS Image Base/SFT through a pinned stable-diffusion.cpp runtime, isolated from the text engine. Native clients provide component installation/import; the desktop app and CLI verify a prepared folder. Every preset requires its complete diffusion model, text encoder, VAE and, for MOSS, tokenizer.

FLUX files require your own publisher access and license decision. Quenderin does not accept those terms for you. Supply a full scene caption; the app does not automatically expand a short FLUX prompt with another model. Generation requires 24 GiB of available memory, supports cancellation and saves a new PNG without overwriting an existing file. A browser dashboard needs the desktop app for local folder selection and generation.

What has been checked, and what remains

Source checks and small host fixtures exercise prompt formats, complete-file verification, conversion receipts, bounded input/output, cancellation, private storage and native interfaces. Specialist work releases idle text weights before checking memory and preserves the selected answer model and conversation. Shutdown joins native work before freeing the shared backend. These checks establish engineering behavior, not full-model quality, speed or peak memory.

No model weights were downloaded locally, and no simulator or physical device was run for this update. The 18 integrated CI jobs passed at engineering revision 1d5f445: Apple and Android native builds, Linux/Windows desktop package probes, the macOS desktop lab package, all three image-runtime builds and Windows private-storage checks. The separate catalog URL check also passed. Full-weight inference, generated-image quality and rendered native UI remain unverified. Native store submissions and Windows/Linux desktop releases are separate steps; no new public app availability is claimed here.
