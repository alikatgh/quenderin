Desktop · source update

Talk to your local model by voice

27 November 2026 · Quenderin

Quenderin’s unreleased desktop dashboard adds push-to-talk dictation. Hold the microphone button, say what you want to ask, and release to transcribe. With the default settings, your words appear in the composer so you can fix a name or finish a sentence before sending.

Two choices in desktop setup

Start with Choose your local chat model. The next step, Talk to your local model by voice, is optional. Pick a speech model or choose Skip — I’ll type. You can set up voice later in Settings → Voice.

  • Recommended. Parakeet Unified English 0.6B is a 697 MB download and Handy’s English pick for the balance of speed and accuracy.
  • More accurate. Qwen3-ASR 1.7B is a 2.0 GB download with lower English word error in Handy’s results.

Open Show all 29 models to search Handy’s curated catalog or use the Live preview and Translates model filters. The table shows English accuracy (EN), speed bars (SPEED), and download SIZE. You can pause or resume a download, or select Finish setup while the download continues. Quenderin checks the catalog’s SHA-256 before installing the model.

From the microphone to your draft

With a speech model installed and enabled, hold the mic in Chat or Device Agent. You can also hold Ctrl+Shift+M on Windows or Linux, or ⌘+Shift+M on macOS. If a microphone permission prompt interrupts the gesture, grant access and hold again. After you release, the local transcribe.cpp runtime processes the recording on your computer.

In Settings → Voice, select Use this model to switch to a different installed speech model. The same section has switches for Enable voice dictation and Automatically send transcript. The release plan limits automatic sending to Chat. The guide covers microphone permissions on Windows, Linux, and macOS Electron lab builds. Microphone permissions

Where the grades and speed bars come from

The English accuracy grades use Handy’s FLEURS results. The speed bars summarize the estimated wait for a 30-second recording on Handy’s AMD Ryzen 4750U GPU benchmark with Vulkan. Quenderin ran no inference benchmarks for this update. Release verification still needs real microphone capture, full-model inference, and packaged Electron testing. Handy’s published benchmarks

We adapted the model picker and resumable download handling from Handy by CJ Pais and use its @handy-computer/models 0.2.3 package for the catalog, recommendations, and grades. Both are MIT-licensed. The picker lists each speech model’s license. Handy on GitHub · Handy’s model package
