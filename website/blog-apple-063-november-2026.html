App update

iPhone 0.6.3 is on the App Store

27 November 2026 · Quenderin

Quenderin 0.6.3 refreshes the on-device engines and model catalogs on iPhone. It adds experimental entries for local image generation with Kromoss, including an optional 8-step mode, and for on-device speech recognition.

What you can install today

iPhone 0.6.3 was released on 24 November UTC (25 November in Ulaanbaatar). Mac 0.6.1 was released on 9 November UTC. iPhone App Store · Mac App Store.

The App Store listing remains unavailable in France. Follow issue #217.

On Android, Google Play closed testing serves 0.2.0. Android 0.6.3 is an unsigned GitHub draft candidate. Download the current apps.

Unreleased work on main

These changes merged to main on 27 November at 11:03 in Ulaanbaatar (6f16e273) and remain unreleased. PR #250.

  • A local API for macOS. The Ollama-style API is loopback-only and off by default. Once enabled, apps on the same Mac can use an installed Quenderin model through the OpenAI-compatible chat endpoint. Local API guide.
  • Thinking modes. Choose Off, Auto, or Hide in chat settings.
  • quenderin run <model> [prompt]. Start an interactive chat or print one reply. The command can download the chosen model if needed.
  • Vision in the Apple chat composer. Still-image support is behind a disabled flag. Vision implementation note.

Experimental entries and verification

Choose an experimental model to start its download. The image and speech integrations were checked with host fixtures. Full-weight inference and device behavior remain unverified. Read the engineering notes.

Local models stay on your device. Local chat needs no Quenderin account. Optional remote destinations receive conversation data only when you choose them. Read the changelog.
