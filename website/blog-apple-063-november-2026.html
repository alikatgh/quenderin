App update

iPhone 0.6.3 on the App Store, and what is still on main

27 November 2026 · Quenderin

Quenderin is a native app for iPhone, Android, and Mac. There is no account. A local model stays on the device, and a local chat is not sent away for an answer. This note separates the app you can install today from the work merged on main that is not in a store build.

What you can install today

Checked on 27 November 2026: iPhone is 0.6.3, released 24 November (25 November in UTC+8). Mac is still 0.6.1, released 9 November, and 0.6.3 is not on the Mac App Store. Open the listing.

The published 0.6.3 notes say the update refreshes the on-device engines and model catalogs and adds experimental entries for local image generation (Kromoss, with an optional 8-step mode) and on-device speech recognition. Experimental entries are manual choices, they are not tested inference, and nothing is downloaded until you choose a model. Local models stay on the device, no Quenderin account is needed, and the optional remote destinations are unchanged and still send data only when you choose them.

Two limits on availability. In France the listing is still unavailable while issue #217 (restore France availability after encryption compliance) is open. On Android, Google Play closed testing still served 0.2.0 at the 24–25 November check, with seven opted-in testers and production inactive. The Android source targets 0.6.3, but the only 0.6.3 Android artifact is an unsigned GitHub draft candidate; it is not a Play release. Download the current apps.

Merged on main, not in a store build

The repository merged PR #250 on 27 November 2026, three days after 0.6.3 shipped. None of it is in a store build, and that merge did not deploy the website.

  • A local API for macOS, off by default. An opt-in server on loopback only (127.0.0.1, default port 11435, next to Ollama's 11434) that serves the OpenAI Chat Completions API. Scripts and editors that accept a custom base URL can use the model already installed in Quenderin. Nothing listens until you turn it on in Settings, and iOS never compiles it.
  • Thinking modes. A chat setting with three choices: Off, Auto, and Hide.
  • quenderin run <model> [prompt]. A CLI shortcut that downloads a model if needed, then starts a chat or prints one answer.
  • Vision in the chat composer, still off. Still images are wired into the main composer, but FeatureFlags.visionInChat is false in both the Swift and Kotlin sources. The apps show no change and keep the existing “vision not available yet” refusal; the separate experimental vision workflow is unchanged.

The source documents are the local API guide and the vision flag note.

What this note does not claim

An experimental catalog entry means the app can select that engine. It is not tested inference, and it does not mean that image or speech inference in 0.6.3 has been tested. No model weights were downloaded for this note, and no simulator or phone was run.

Mac has no 0.6.3 release, and Android has no signed 0.6.3 artifact. Those are separate release gates. Read the changelog or follow the commit history.
