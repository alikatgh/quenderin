Kromoss local images and native Hex speech across Quenderin

22 November 2026 · Quenderin

Quenderin is expanding from offline text chat into multimodal local creation and voice interaction without asking users to install separate companion apps. Alongside today’s 30-page documentation portal and self-hosted typography rollout, we have integrated two major open-source projects directly into Quenderin’s cross-platform native stack: Kromoss for fast local image synthesis and Hex + transcribe.cpp for local speech recognition and dictation.

Kromoss and 8-step DMD2 image generation

Kromoss (Apache-2.0) builds on the open MOSS Image architecture and adds an optional 8-step DMD2 LoRA accelerator (CFG 1.0, flow shift 5.0). Rather than duplicating weights or rewriting inference from scratch, Quenderin integrates Kromoss cleanly onto our existing symbol-isolated diffusion pipeline:

  • Shared encoders, zero bloat. Both kromoss and kromoss-dmd2 reuse the pinned Qwen3.5-9B text encoder, Flux2 VAE, and MOSS tokenizer already declared in shared/image-model-catalog.json.
  • C ABI v2 + QKV LoRA patch. Upgrading native/diffusion to ABI v2 introduces lora_path, cfg, and flow_shift alongside a source patch that maps unfused proj.q/k/v DMD2 LoRA tensors onto stable-diffusion.cpp’s fused proj.qkv layers.
  • End-to-end across every client. Wired across Desktop CLI (quenderin image), Apple Swift (QuenderinKit), and Android Kotlin (quenderin-core), with SHA-256 verification before native load and non-overwriting PNG creation.

Native Hex and transcribe.cpp speech across 20 models

Hex and transcribe.cpp (MIT) bring production-grade, multi-engine speech recognition and deterministic dictation formatting without cloud audio upload:

  • 20 pinned speech presets + Silero VAD v6.2. shared/speech-model-catalog.json catalogs Parakeet (Unified EN, v2, v3, Ultra), Orukeet, Fluid Speech Pro, Whisper Large v3 Turbo, Qwen3-ASR 0.6B/1.7B, SenseVoice Small, Cohere Transcribe, Nemotron 3.5 ASR, GigaAM v3, Granite Speech 5.0, Ivrit/NB/KB-Whisper, and on-device Apple Speech.
  • Isolated C ABI + loopback v2 SDK. native/speech runs in its own private GGML build (quenderin_speech_*, quenderin-speech-cli, and Android JNI) so symbol namespaces never collide with text inference, while Desktop HexSpeechAdapter supports both hex service --embedded Bearer HTTP/SSE and direct CLI execution via quenderin voice and VoiceService.
  • MIT dictation pipeline on every OS. Custom vocabulary spelling, spoken punctuation, spoken lists, filler removal, and French spacing run identically in TypeScript, Swift, and Kotlin—while keeping private spoken transcripts out of disk logs.

Honest verification scope

As with all experimental model additions in Quenderin, source integration is explicitly separated from live weight inference and store distribution:

  • Verified today on host toolchains: Catalog parity and SHA-256 validators across all manifests, symbol-isolated C/C++ shared libraries and CLIs compiled against synthetic fixtures, Swift/Clang resource cleanup and cancellation harnesses, Kotlin core compilation and runtime checks, and Desktop TypeScript unit tests (including Hex loopback HTTP/SSE handshakes and quenderin-speech-cli subprocess bounds).
  • Remains outside this source milestone: Multi-gigabyte weight downloads and end-to-end audio/image inference on end-user weights (inferenceVerified: false), simulator/physical phone UI runs, and public App Store / Google Play submissions. Mac and iPhone on the App Store remain 0.6.0 (0.6.1 in source), and Android remains in closed beta (0.2.0).
