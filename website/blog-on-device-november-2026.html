App update

A chosen model, one note, and checks on the device

9 November 2026 · Quenderin

Quenderin is a native app for iPhone, Android, and Mac. There is no account. A local model stays on the device, and a local chat is not sent away for an answer. This note separates the app you can install today from the behavior that is in the source and not yet a store build.

What you can install today

Checked on 9 November 2026, Mac and iPhone 0.6.0 are on the App Store, released 1 November 2026. Open the listing. The published notes add optional DeepSeek with your own key, and an optional connection to a computer you prepare. They also cover automatic model choice among installed models, recovering a remote draft, formatted replies, copying code, and when Stop and Continue apply. Local chat in that build still needs no account.

That store app does not include the newer behavior below. The public Google Play page for the Android app is not a production listing. Android remains a closed test, and version 0.6.1 has not been uploaded there. Download the current apps.

The next candidate, still on this machine

Version 0.6.1 is prepared in the source for iPhone, Android, and Mac. It has not been submitted to the App Store or Play. You still choose a model and download it yourself. When you have no chats yet, the app opens a new one. There is no account to create.

  • Keep a chosen model. If you pick a model and the file is missing, cannot be read, does not run in this build, or does not fit memory, that choice stays selected. The app does not quietly swap in another model. If you have not chosen one, it can still recommend.
  • A named note. You save a note under a name, then choose that name. One note is active. It does not change the model or which tools can run.
  • One writer. One reply owns the conversation. A second reply waits until the first one finishes.
  • A cancelled download. Stopping a download returns you to the model choice. A model that already loaded stays selected.
  • Local tools you can turn off. Calculator, units, and dates start on. Turn one off and it does not run.
  • A reply held on the device. A local reply that mentions a sensitive action is not shown. Nothing is sent.

Optional DeepSeek, Step 5, and a prepared computer are unchanged. Each sends data only after you choose that destination. On iPhone, the chat keyboard has a Done control that dismisses it and keeps what you typed. On iPhone and Mac, a reply can be read by the accessibility tools from the text on screen. Those two fixes are in the source; the published 0.6.0 notes do not list them, so this page does not treat them as part of the store build.

The candidate is the local-chat source, prepared as 0.6.1 and not submitted.

Five more behaviors, same source, same limit

After that candidate, the source on main also includes five behaviors for the same three apps. They are not a new store release. Choosing one does not download a model file.

  • A checker model. You can select a model that is already on the device. Before a reply or a tool result is shown, that model can be asked. If the file is missing, nothing is downloaded. If you do not select one, a shape and word check still runs on the device.
  • Look and Listen. Photos and speech stay closed until you open them. If you select a photo or speech model that is already on the device, Look and Listen load that file for the sample, then restore the previous model. A missing file is not downloaded.
  • Local tools. Besides the switches above, a tool server is allowed only on this device. On Mac, you can name a command. A checkup does not run a tool by itself.
  • Doctor. A checkup of what is on the device: the chat model, the checker, photos and speech, notes, and tools. It does not start a chat and does not run a model.
  • Practice. Saved questions score calculator, units, and dates. Practice does not score the model.

This work is in the source for iPhone, Android, and Mac.

What this note does not claim

This is not tested inference. Doctor does not run a model. Practice does not score a model. Selecting a checker, or opening Look and Listen, does not by itself prove that a full model produced an answer.

An experimental catalog model is source support. The app can say so when you select one. That label is not a tested run, and it is not a store release.

No signed 0.6.1 build was produced for this note, and nothing was uploaded to the App Store or Play. No model weights were downloaded here, and no simulator or phone was run. Read the changelog or follow the commit history.
