Website update

We’ve rewritten the website copy

8 October 2026 · Quenderin

We’re sorry for the copy we were using on this website. It was too salesy, sometimes jokey, and too certain about what the software could do. It made a free, open-source project sound like a sales pitch. That was our responsibility, and we should have described it more carefully.

We’ve rewritten the homepage and shared wording into factual descriptions, and updated the wording in all 12 website languages. This is a website update, not an app release. It changes how we explain the project; it does not add features to the software.

Quenderin is a free, open-source app for running language models on your own device. After you install a model, chat can run offline. Model downloads, model search, and release metadata use an internet connection. Saying “offline” without that distinction left out part of the setup and the app’s network activity.

We’ve also qualified claims about tools, approvals, and undo. The apps and the source command-line interface do not all provide the same capabilities. The source CLI has undo for supported file operations; that is not a promise that every action can be reversed, or that the same controls are available in every app.

Setup takes storage, and running a model takes memory and processing power. A model may be too large for a device, run slowly, or produce an incorrect answer. We’ve made those limits clearer. Local processing describes where the work happens; it does not guarantee speed or accuracy.

The changelog records this wording update. Our measured results give more context for performance claims. The standard for this site should be straightforward: explain what is available, distinguish it from what is limited or still in development, and give readers enough information to decide whether it fits their needs.
