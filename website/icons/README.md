# Model discovery marks

family colors. No artwork was downloaded, regenerated or represented as newly
licensed. Marks identify the original model namespace in `baseModel`; the GGUF
publisher is separately named in text. They do not describe a partnership or
endorsement. Unknown authors retain their model names without a guessed mark.

## Guideline qualification, checked 28 October 2026

[Microsoft's guidelines](https://www.microsoft.com/en-us/legal/intellectualproperty/trademarks)
distinguish truthful name references from logos, which require express licensing.
[NVIDIA's guidelines](https://www.nvidia.com/en-us/about-nvidia/legal-info/logo-brand-usage/)
also require written authorization, describe identification/educational uses
among approved examples, and prohibit separating the eye mark from the wordmark.
Those restrictions are not limited to paid advertising; model identification on
this marketing site does not itself prove permission. Existing repository
provenance is not a trademark license. The release review must assess the actual
composition and these qualifications, particularly the pre-existing eye-only
NVIDIA asset. This update does not modify any SVG geometry or add endorsement
claims.
