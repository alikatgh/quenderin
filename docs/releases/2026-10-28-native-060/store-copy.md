# Native 0.6.0 store drafts

Prepared 28 October 2026. An editable store draft is not a submitted update.

## Apple description

Quenderin runs open language models on your device. Download a compatible model for local offline chat, or explicitly choose a separate remote destination. Local chat needs no Quenderin account.

• Choose models with download sizes, compatibility checks and memory estimates. Automatic selection uses available device and performance information; manual choices remain available.
• Keep local conversations on your device. Saved Hy-Memory facts require your review and approval.
• Optionally connect to DeepSeek using your own API key. That destination sends its conversation to DeepSeek under your provider account and billing terms.
• Optionally connect to your own prepared Remote Harness server and trusted computer. Review the destination, trust and action approvals before remote work. Quenderin does not provide or provision a hosted AI service.
• Read formatted replies, copy code, retain separate drafts and recover interrupted remote sessions.
• Use separate workflows for still-image questions, verified Granite imports and local image generation on suitable hardware. Step 5 remains a separately approved connection to your prepared CUDA host.

Large models need complete downloads and substantial memory. Some specialist workflows are unavailable on ordinary phones. Experimental catalog entries are manual choices; file size and active parameter count are not RAM requirements.

Internet access is needed for downloads, discovery and remote destinations. Local inference works offline after setup. Optional remote processing transmits data to the destination you select; its operator controls retained copies. On-device and remote models can make mistakes. Check important answers.

## What's new

Added separate optional destinations for DeepSeek with your own API key and your prepared Remote Harness computer, with destination-specific conversations, trust and approval controls.

Improved local Automatic model selection, remote drafts and session recovery, formatted messages and code copying. Fixed Stop settlement so accepted text is preserved, while navigation and cancelled turns do not become completed replies. Continue is offered only after a confirmed token-budget stop.

Improved accessibility, error recovery and Unicode number parsing. Updated privacy disclosures to distinguish local inference from optional provider and computer connections.

## App Review notes

The local app requires no sign-in or review account. Choose and explicitly download a small compatible model over Wi-Fi for ordinary local chat. No model download or server provisioning starts automatically. Large Beam/Muse/workstation models are unsuitable for an ordinary iPhone.

DeepSeek is optional and requires the user's existing provider API key. My computer is optional and requires the user's prepared Remote Harness server/account and trusted computer. Neither is a Quenderin-hosted subscription or a prerequisite for local chat. Local conversation history is separate from those destinations. The privacy policy explains each route, credentials, consent and retention boundaries.

Settings exposes the separate still-image, approved-memory, Granite and Step 5 workflows. Resource gates intentionally leave unsuitable workflows unavailable. MAX remains unavailable; its source bindings do not establish a shipping backend.

Record the exact signed build, source, cloud test attachments and remaining verification limits in RELEASE.md before submission. Do not claim live provider/Host execution, physical-device tests or full-model inference from synthetic fixtures or compilation.

For Mac, verify main-window closure/relaunch and Settings-only behavior in the selected candidate. Historical behavior is not current execution evidence.
