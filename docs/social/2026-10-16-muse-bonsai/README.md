Facebook also links the [changelog](https://quenderin.org/changelog). They describe
manual Bonsai 2 2B/4B/9B choices, approximately 0.43/0.95/2 GB downloads, memory

totaling roughly 304 GB. They explicitly state that full-weight Muse inference
has not been validated. LinkedIn distinguishes synthetic CPU decode/save-reload
checks from full-weight inference.

The captions say iOS/macOS 0.4.0 were submitted for Apple review and Android's
build is prepared with its Play upload pending, consistent with `docs/RELEASE.md`.
They do not claim public store distribution, Muse on ordinary phones, multimodal
support, distributed execution, measured Muse speed, or native UI validation.
No ads, boosts, subscriptions, paid API generation or model downloads were used.
