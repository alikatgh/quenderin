## Published Page caption — Facebook and LinkedIn

This week’s open models in Quenderin: an engineering update.

The source now has 28 text-model choices, including Jais 3, Nemotron 3.5 Bolt,
LFM2.5 and MiniCPM-V 4.7. Beam and Muse have complete multipart installation and
native/desktop chat adapters. Their full weights still need workstation-scale

Separate workflows let you ask about a still image with MiniCPM or Super VL,
review Hy-Memory proposals before saving selected facts, import a verified
Granite Switch 4.1 conversion for chat, and generate images with FLUX 3 Image
Klein or MOSS. Step 5 connects to your own existing CUDA host after consent;
it does not run on the phone. Gated FLUX files and license decisions remain yours.

desktop package checks have passed. Full-weight inference, image quality and native
device UI have not been verified. The article gives each model’s setup path,
